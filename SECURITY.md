# Security Policy

## Supported Versions

Security fixes apply to the latest release on the `main` branch and active integration changes on `dev`.

| Branch or Version | Supported |
| :---------------- | :-------- |
| `main` (`v1.x`)   | Yes       |
| `dev`             | Yes       |
| Older commits     | No        |

## Reporting a Vulnerability

Do not open public GitHub issues for security vulnerabilities, credential leaks, payment bypasses, or privilege escalation bugs.

Use GitHub Security Advisories at [github.com/MinhPhuc00ne/project-nexus/security/advisories/new](https://github.com/MinhPhuc00ne/project-nexus/security/advisories/new) to report issues privately.

Include the following details in your report:

- Affected component, endpoint, or WebSocket event.
- Reproduction steps or a minimal proof of concept.
- Expected impact and suggested remediation if known.

Maintainers acknowledge private security reports within 72 hours and coordinate fixes before public disclosure.
